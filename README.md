# Custom Video Player

Кастомный HTML5 видеоплеер с пользовательской панелью управления на базе библиотеки Playable. Проект демонстрирует интеграцию стороннего API плеера с собственными элементами интерфейса и кастомной стилизацией.

Опубликованная версия сайта **https://daschaosipova.github.io/video-player/**

## Особенности проекта

- **Кастомный интерфейс**: Панель управления, реализованная на HTML/CSS (иконки Font Awesome).
- **Библиотека Playable**: Использование готового бандла `playable.js` для управления видеопотоком.
- **Адаптивная верстка**: Панель управления построена на Flexbox с поддержкой автоматического распределения свободного пространства.

## Структура репозитория

- `index.html` — главная страница плеера с HTML-разметкой и стилями.
- `player.js` — JavaScript-логика инициализации плеера и привязки событий к кнопкам.
- `font-awesome/` — локальные файлы шрифтов и стилей для отображения иконок управления (Play, Pause, Mute, Fullscreen).

## Стек технологий

- HTML5 & CSS3 (Flexbox)
- JavaScript (ES6+) & jQuery 3.4.1
- [Playable.js](https://unpkg.com) — библиотека для управления видео
- [Font Awesome](https://fontawesome.com) — библиотека иконок

## Локальный запуск

1. Склонируйте репозиторий на свой компьютер:
```bash
git clone https://github.com/daschaosipova/video-player.git
```
2. Перейдите в папку проекта:
```bash
cd video-player
```
3. Откройте файл `index.html` в любом современном браузере.

## Кастомизация

Центральное пустое пространство на панели управления (`.player-blank-space`) подготовлено под будущее расширение. Сюда можно интегрировать:
- Ползунок прогресса воспроизведения (Timeline).
- Текущее и оставшееся время видео.
- Регулятор громкости.
